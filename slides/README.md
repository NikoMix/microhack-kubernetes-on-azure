# `slides/` — Classroom decks (Marp)

Instructor slide decks authored in **Marp** (Markdown → HTML/PDF, MIT).

## Scope

- One deck per module (M0–M6) + an intro/orientation deck + a wrap/Train‑the‑Trainer deck.
- Concise, visual; speaker notes for facilitators; consistent theme.

## Conventions

- Source `*.md` with Marp front‑matter; shared theme in `themes/`.
- Export to `dist/` (HTML + PDF) via CI using `@marp-team/marp-cli`.
