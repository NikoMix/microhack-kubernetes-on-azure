# Trainer-only solutions

These completed examples are trainer-only reference outputs for M2. Use them to calibrate feedback against B.2.1 evidence requirements; do not give them to learners before they submit their dependency map and remediation backlog.

## Files

- `dependency-map-example.md` provides a filled dependency map and category tables.
- `remediation-backlog-example.csv` provides a realistic prioritised backlog.
