## Course glossary

| Term | Meaning |
| --- | --- |
| ACR | Azure Container Registry, the private registry used for container images. |
| AKS | Azure Kubernetes Service, Microsoft's managed Kubernetes service. |
| Azure CNI Overlay | AKS networking mode that gives pods overlay IPs while nodes use VNet IPs. |
| Azure MCP | Model Context Protocol server used by Copilot to inspect Azure resources. |
| Azure Policy for AKS | Azure governance integration that audits or enforces Kubernetes configuration. |
| Bicep | Azure infrastructure-as-code language used for the primary secure-baseline deployment. |
| CKA | Certified Kubernetes Administrator certification. |
| CKAD | Certified Kubernetes Application Developer certification. |
| CKS | Certified Kubernetes Security Specialist certification. |
| Container Insights | Azure Monitor capability for AKS logs, metrics, and container inventory. |
| CSI | Container Storage Interface; in this course, often used with Key Vault CSI Secret Store. |
| Defender for Containers | Microsoft Defender plan for container and Kubernetes security posture and threat detection. |
| Entra ID | Microsoft identity platform used with AKS authentication and Azure RBAC. |
| Flux | GitOps operator that reconciles Kubernetes desired state from Git. |
| GitHub MCP | MCP server used by Copilot to inspect repository and GitOps context. |
| GitOps | Operating model where Git stores desired state and an operator reconciles it into the cluster. |
| HLD | High-level design document describing architecture decisions and rationale. |
| Ingress | Traffic entering the cluster, usually through an ingress controller or application gateway. |
| Key Vault | Azure service for secrets, keys, and certificates. |
| Kubectl | Kubernetes command-line tool for inspecting and changing cluster resources. |
| Log Analytics | Azure Monitor workspace used to store and query logs. |
| Managed identity | Azure identity assigned to a resource or workload without storing credentials. |
| Microsoft Docs MCP | MCP server used by Copilot to ground answers in Microsoft documentation. |
| Namespace | Kubernetes logical grouping boundary for resources. |
| Node pool | Group of AKS nodes with shared size, mode, and configuration. |
| OIDC issuer | AKS endpoint used for federated identity and Workload Identity. |
| Pod | Smallest schedulable Kubernetes unit, usually running one application container. |
| RBAC | Role-based access control for authorising actions in Azure or Kubernetes. |
| SLI | Service level indicator, a measured signal such as availability or latency. |
| SLA | Service level agreement, a formal commitment usually tied to support or contract terms. |
| SLO | Service level objective, the target threshold for an SLI. |
| SOW | Statement of work, a delivery artifact that describes scope, assumptions, and responsibilities. |
| Triage runbook | Step-by-step operational guide for diagnosing and responding to incidents. |
| WAR | Well-Architected Review against architecture pillars such as Reliability and Security. |
| Workload Identity | AKS feature that lets pods access Azure resources through federated managed identity. |
