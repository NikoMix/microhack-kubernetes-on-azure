## What this is

This is the **published companion site** for a complete, ready-to-deliver MicroHack
that teaches trainers how to run a 1-day, classroom-led course on **Kubernetes on
Azure**. It mirrors the hands-on labs in
[`challenges/`](https://github.com/NikoMix/microhack-kubernetes-on-azure/tree/main/challenges),
the [`slides/`](https://github.com/NikoMix/microhack-kubernetes-on-azure/tree/main/slides),
and the [`trainer-guide/`](https://github.com/NikoMix/microhack-kubernetes-on-azure/tree/main/trainer-guide).
